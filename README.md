# Wave — музыкальный плеер для Vercel

Статический интерфейс и серверные функции Vercel. На главной показывается история последних 100 разных треков, воспроизведение которых успешно началось. Она хранится в браузере на конкретном устройстве и не синхронизируется между аккаунтами; очистка данных сайта удалит её. Повторное прослушивание поднимает трек наверх. Лайки, плейлисты и позиция плеера, как и раньше, хранятся в браузере.

## Размещение на Vercel

1. Загрузите **содержимое** этой папки в репозиторий GitHub (не публикуйте секреты).
2. На Vercel выберите **Add New → Project**, импортируйте репозиторий. Framework Preset — **Other**, команда сборки не требуется. Корневая папка проекта должна содержать `index.html`, `api` и `package.json`.
3. В настройках проекта **Environment Variables** добавьте `YAM_TOKEN` — OAuth-токен Яндекс Музыки. Без него поиск, чарт и воспроизведение не работают.
4. Если нужны аккаунты, профиль и админка, создайте постоянную базу **Turso/libSQL** и добавьте в Vercel переменные `TURSO_DATABASE_URL` (например, `libsql://...`) и `TURSO_AUTH_TOKEN`. Токен должен разрешать чтение и запись. Создавать таблицы вручную не нужно.
5. Для администратора задайте секрет `ADMIN_CODE`; необязательно задайте `ADMIN_USER` (по умолчанию `bibnaq`). При регистрации этого имени введите админ-код. Без базы регистрация и профиль недоступны; история прослушиваний продолжит храниться в браузере.
6. Выполните Deploy; после изменения переменных окружения перезапустите развёртывание. Домен Vercel доступен по HTTPS.

> Важно: база Cloudflare D1 из старой версии не переносится автоматически. Новая база Turso будет пустой; перенос старых аккаунтов и подборок требует отдельной миграции данных. Браузерная история, лайки и плейлисты привязаны к домену: при переходе на новый домен Vercel браузер не перенесёт их автоматически.

## Переменные окружения

| Имя | Назначение |
| --- | --- |
| `YAM_TOKEN` | OAuth-токен Яндекс Музыки, обязателен для музыкального API |
| `TURSO_DATABASE_URL` | адрес базы Turso, обязателен для аккаунтов |
| `TURSO_AUTH_TOKEN` | токен базы Turso, обязателен для аккаунтов |
| `ADMIN_CODE` | секретный код для регистрации администратора |
| `ADMIN_USER` | имя администратора, по умолчанию `bibnaq` |

Не храните реальные секреты в коде и GitHub. `.env.example` содержит только имена переменных.

## Локальный запуск

Для полной проверки серверных функций запустите `vercel dev` из корня проекта, предварительно настроив переменные окружения. Обычный статический сервер покажет интерфейс, но не запустит API. Нужен Node.js 20 или новее.

## Ограничения

Используется неофициальный API Яндекс Музыки, который может измениться. Соблюдайте условия сервиса и авторские права. Для реальной проверки музыки нужны рабочий токен и доступ к сервису, для проверки регистрации — действующая база Turso.
